# Password Security Analyzer

A Python cybersecurity project that analyzes password strength and provides
recommendations for improving password security.

## Features

- Evaluates password length
- Detects uppercase and lowercase characters
- Detects numbers and special characters
- Identifies common weak passwords
- Generates a password security score
- Provides recommendations for weak passwords
- Generates random strong passwords

## Technologies

- Python 3
- Python `random` module
- Python `string` module

## What I Learned

This project helped me practice Python functions, loops, conditionals,
lists, string operations, and password security concepts.

## How to Run

1. Download or clone the repository.
2. Make sure Python 3 is installed.
3. Run:

python password_analyzer.py
